# Ebook Marketplace — Antigravity Build Prompt

## Project Goal

Build a modern, clean, minimal ebook marketplace website where users can:

* Browse ebooks
* Search for books
* View book details
* Purchase ebooks
* Read purchased ebooks online
* Track reading progress
* Continue reading unfinished books
* Manage their personal library

The overall visual direction should be **simple, modern, minimal, soft pastel, premium, and friendly**.

Do NOT make the website look like a traditional bookstore. It should feel closer to a modern SaaS/productivity application with an elegant reading experience.

---

## Visual Design

### Design keywords

* Minimal
* Modern
* Clean
* Soft pastel
* Premium
* Friendly
* Spacious
* Rounded
* Soft shadows
* Lots of whitespace
* Simple typography
* Subtle animations

### Color palette

Use a mostly white background.

Primary accent:

* Soft lavender / purple
* Example: `#8B6FD8`

Secondary pastel colors:

* Soft pink
* Soft blue
* Soft green
* Soft peach
* Very light lavender

Avoid:

* Very saturated colors
* Heavy gradients
* Dark backgrounds
* Excessive glassmorphism
* Excessive shadows

Use pastel colors mainly for cards, badges, icons, buttons, and highlights.

# Responsive Design

The website MUST be fully responsive.

Desktop:
1440px+

Tablet:
768px–1439px

Mobile:
320px–767px

Mobile design should not simply shrink the desktop layout.

Reorganize components appropriately.

For example:

Desktop navbar:
Logo → navigation → search → cart → profile

Mobile navbar:
Logo → search → cart → hamburger

Hero section:

Desktop:
Text left + illustration right

Mobile:
Text first + illustration below

Book grids should automatically adapt.

# Final Design Direction

The final result should resemble a premium modern ebook platform.

Think:

Apple-like simplicity
+
Notion-like cleanliness
+
modern bookstore
+
soft pastel colors
+
cozy reading experience

Use generous whitespace, rounded cards, subtle borders, soft shadows, pastel accents, and excellent typography.

The UI should look polished enough to be used as a real portfolio project.

Most importantly:

**Keep it simple.**
**Do not overcrowd the interface.**
**Whitespace is part of the design.**
**Pastel colors should be subtle, not overwhelming.**
**The reading experience should feel calm and comfortable.**
